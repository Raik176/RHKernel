◆ PageFlags

enum class vmm::PageFlags : uint64_t
strong

Page table entry flags for x86-64 paging.

These flags map directly to hardware-defined bits in x86-64 page table entries (PML4E/PDPTE/PDE/PTE).

Enumerator
None 
Present 

Page is present in memory

Write 

Page is writable

User 

Page is accessible from user mode (ring 3)

WriteThrough 

Write-through caching

NoCache 

Disable caching (useful for MMIO)

Accessed 

Page has been accessed (set by CPU)

Dirty 

Page has been written to (set by CPU)

Huge 

Page is a large page (2 MiB or 1 GiB)

Global 

Global page (not flushed from TLB on CR3 reload)

CoW 
NX 

Disable instruction fetch (NX bit)
