◆ init()

void heap::init ( )

Initialize the kernel heap.

Currently, this only sets up internal slab structures. In a more complex system, mutexes and bookkeeping would also be initialized.

Sets up the slab allocator structures and prepares memory for dynamic allocation using kmalloc/kfree.

void * heap::kmalloc ( size_t  size)

Allocate memory from the kernel heap.

Finds a suitable slab cache for the requested size and returns a free slot. If no suitable slab exists, a new slab is created.

Parameters

Returns
